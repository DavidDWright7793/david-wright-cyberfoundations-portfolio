## In My Own Words

**What's the difference between a file and a folder, and how do they form a tree together?**

```
In PowerShell and Bash, a file stores raw data or text, while a folder is a container that organizes files and other folders. In other words, a folder is like a tree, and files are branches on the tree.
```

**How does a Windows-style file path differ from a Linux-style file path?**

```
There are several notable differences between a Windows-style path and a Linux-style path. One is that Windows uses a backslash (\) to separate folders in a path, while Linux uses a forward slash (/) for that task. Also, Linux file paths are case-sensitive, while Microsoft paths are case-insensitive. In other words, whether a letter is uppercase or lowercase matters in Linux, but not in Windows.
```
